About PolicyForge AI

A small lab for comparing scheduling policies, checking requirements and learning from counterexamples.

What you can do

Define jobs and a measurable goal, compare FCFS, SJF, Priority and Round Robin, then inspect the execution timeline. Search generated workloads for a failure and replay a reduced example.

Open Scheduling Lab →

The AI components

Trained scheduler advisor
A supervised decision tree learns from 192 simulator-labelled workloads and tests on 48 separate examples. It scores 32/48 correct (66.7%). The simulator checks its prediction.
Local retrieval tutor
TF-IDF and cosine similarity match questions to 113 example questions across 21 topics. Numerical examples come from the simulator.
Optional generative tutor
A Gemini or OpenAI model connection can add generated explanations using supplied experiment evidence. It requires a server-side API key and explicit selection in the tutor. It remains inactive without configuration.

How the pieces connect

Browser HTML, CSS and JavaScript send JSON to a Python HTTP server. core.py runs scheduling algorithms. experiments.py checks goals and searches for failures. advisor.py runs the trained tree. tutor.py retrieves lessons. llm_tutor.py connects the optional language model.

Scope and limitations

One simulated CPU, known bursts, finite jobs and no I/O blocking. The goal parser supports specific phrases. Synthetic training data does not prove real-world scheduler performance. The model cannot learn a winning class absent from training, such as Priority in this dataset.

This project does not change macOS scheduling or manage real processes. It requires no external Python packages.
